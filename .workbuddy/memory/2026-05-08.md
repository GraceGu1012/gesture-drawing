## 新增功能：鼠标画图 + 简笔画 + 涂色

- 添加鼠标/触摸画图支持（mousedown/move/up + touch 事件）
- 添加三种工具模式：画笔、涂色、橡皮擦（工具栏模式切换按钮）
- 涂色功能使用 flood fill 算法，点击封闭区域填充当前颜色（容差 30）
- 添加简笔画面板（🎨 简笔画按钮），提供 12 个 SVG 线稿模板：
  猫、房子、星星、花朵、心形、大树、小鱼、太阳、月亮、兔子、蝴蝶、彩虹
- 简笔画以 SVG 形式绘制到画布中央，颜色跟随当前选中颜色，适合涂色
- 即使摄像头不可用也能正常使用鼠标画图和涂色功能（优雅降级）

- 手指伸直检测从单一 TIP vs MCP 改为 TIP vs PIP vs MCP 三点综合判断（2/3 通过即认为伸直）
- 拇指判断改为 TIP vs IP vs palm center 距离对比
- 捏合阈值从 0.07 放宽到 0.09
- 检测置信度从 0.7/0.6 降到 0.5/0.5
- 添加 5 帧滑动窗口防抖（3/5 一致才切换手势）
- 添加实时手势状态显示栏（画图中/悬停/橡皮擦）
- 添加调试面板显示各手指状态和捏合距离
